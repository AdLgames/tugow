Use whenever an Adversary has announced a box — it replaces reading the announcement out of a side panel.

```jsx
<DeclarationPlacard adversary="The Magpie" box="Sixes" rule="Sum of 6s x 6" />
```

Place it on the felt, not in UI chrome, and keep the matching `BoxRow` marked `declared` — the chit and the card always agree. Vary `tilt` between floors so it reads as a thrown object.
